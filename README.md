# 💰 FinSmart — Smart Expense Tracker

## 🧾 Overview
FinSmart is a modern, responsive **Expense Tracker** built using **React + Tailwind CSS**.  
It allows users to easily manage their expenses, categorize transactions, visualize spending patterns, and maintain financial control with an elegant UI.

---

## 🚀 Features
- ✅ Add, Edit, and Delete Expenses  
- ✅ Category-based expense tracking  
- ✅ Real-time filtering and search  
- ✅ Interactive charts using Recharts  
- ✅ Beautiful and responsive UI  
- ✅ API integration using Axios  

---

## 🛠️ Tech Stack
| Technology | Description |
|-------------|-------------|
| **React.js** | Frontend framework |
| **Tailwind CSS** | Styling and layout |
| **Recharts** | Data visualization |
| **Lucide-React** | Icon library |
| **Axios** | API requests |
